# MechaMinds

An **AI-powered robotic arm** built using an **ESP32** and a **Realtek AMB82 Mini AI Camera**. MechaMinds combines a **Teach-and-Repeat** system with **real-time object detection**, showcasing the integration of embedded systems, computer vision, and IoT for intelligent robotic automation.

---

## **Features**

* 🤖 Teach-and-Repeat motion recording and playback
* 🧠 Real-time AI object detection
* 📡 ESP32-based robotic arm control
* 🌐 Web-based control dashboard
* ☁️ Firebase Realtime Database integration
* 🖨️ Custom 3D-printed robotic arm
* 📶 Wireless operation over Wi-Fi

---

## **Hardware**

* ESP32 Development Board
* Realtek AMB82 Mini AI Camera
* Servo Motors
* External 5V Power Supply
* 3D-Printed Robotic Arm

## **Getting Started**

1. Clone the repository.
2. Upload the firmware to the ESP32.
3. Configure Firebase and Wi-Fi credentials.
4. Launch the web dashboard.
5. Power the robotic arm and start controlling, recording, or replaying movements.
